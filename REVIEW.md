# Зміни для перегляду

Перевірено 04.10.2026 за SPEC.md. Бот для групи 141, підгрупи 1: українські команди розкладу, приватний доступ власника, SQLite, ручне оновлення XLS та нагадування. Постійна робота узгоджена на Linux/VPS із systemd.

## Виправлено під час перевірки

- Помилки фонових служб тепер завершують процес: systemd може перезапустити бота, якщо нагадування або перевірка джерела припинили працювати.
- Токен маскується в повідомленнях журналу та трасуваннях винятків. Конфігурація приймає лише Europe/Kyiv, як вимагає SPEC.
- Імпорт відхиляє некоректні предмети й конфліктні нові записи ОНС, зберігаючи останній робочий розклад. Показує кількість змінених записів; попередній перегляд обох типів тижня доступний без зміни SQLite.
- Додано отримання власного Telegram ID без передачі його стороннім ботам, шаблон systemd та повну інструкцію запуску.
- Реальні розклади, SQLite, секрети й особисті шляхи виключено з файлів для коміту; додано локальну перевірку перед публікацією.

## Перевірено

- 62 автоматизовані тести: команди й доступ, імпорт, атомарні оновлення, застарілі дані, налаштування, нагадування, перезапуск, конкурентні спроби, скасування й перенесення занять, межі часу, зміна тижня, літній/зимовий час та завершення служб.
- `pip check`: несумісних залежностей немає. Версії зафіксовано в requirements.lock.txt.
- Реальний XLS читається; початкова версія містить 22 записи до застосування особистого правила ОНС. Перегляд двох типів тижня працює без Telegram.
- Перевірка файлів для коміту та історії Git не виявила токенів; приватні файли ігноруються. `git diff --check` проходить.

Тести використовують тимчасові бази й підроблену сесію Telegram. Реальна доставка та служба systemd на VPS ще не перевірялися. Зміни підготовлено локально; публікація в GitHub не виконувалася.

## Потрібно для запуску

- Приватно налаштувати токен BotFather та Telegram ID власника; виконати /start.
- Надати адресу й доступ до VPS, встановити Python 3.12 та розгорнути службу за README. На сервері перевірити unit-файл, журнали й реальне нагадування.
- Час ОНС підтверджено 04.10.2026: 13:00, 14:40 і 16:10; нагадування активні й перевірені автоматизованим тестом. Додати онлайн-посилання, коли воно буде відоме.
- Уточнити ОНС після 23.10.2026 та правила нового семестру перед подальшим використанням.

При невідомому результаті запиту Telegram бот не повторює відправку, щоб уникнути дубліката. У такому випадку або при аварії між резервуванням і відправкою нагадування може бути пропущене. Цей компроміс описано в README; журнал подій потрібно зберігати разом із SQLite.
